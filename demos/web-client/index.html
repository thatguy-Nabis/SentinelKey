SentinelKey Web Client

A dummy website that signs in, scans URLs/files, encrypts fields, and reads the IDS feed.

Sign in / Register

The first registered account becomes admin (unless a bootstrap admin is configured). Use admin for full access to every demo below.

Two-factor authentication required

Enter the 6-digit code from your authenticator app.

URL / Link Scanner

Scored by the API's phishing rules (lookalike domains, href mismatch, bad TLDs).

Text Scanner

File Scanner

Full-file SHA-256 + content sent to the classifier (magic-byte, entropy, extension, hash rules).

Field Encryption

Round-trips a secret through the API's AES-256-GCM field encryption.

IDS Feed

Pull the most recent security events and intrusion alerts.

Results

Points the browser directly at the SentinelKey API (CORS is open). Requires the API + MongoDB running locally. Endpoints used: /auth/login|register|mfa/verify, /classify/email|file, /files/encrypt-field|decrypt-field, /logs, /alerts.
